INSIDE THE IMPLEMENTATION

Model components, explained.

Rather than calling a pretrained encoder for classification, the project constructs attention and Transformer blocks directly from PyTorch layers. The same code supports a manual attention path and an optimized SDPA path.

01

Hand-built attention

Q, K and V projections, scaled attention scores, padding masks and a learned output projection.

02

Optimized SDPA option

Switch between explicit attention math and PyTorch’s scaled dot-product attention using --sdpa.

03

Positional encoding

Fixed sinusoidal positions give the encoder sequence-order information without learned position parameters.

04

Pre-LayerNorm blocks

Configurable encoder layers with residual paths and LayerNorm before both attention and feed-forward branches.

05

GELU feed-forward

Each block applies two linear transformations with a GELU nonlinearity, followed by a residual connection.

06

Padding-aware pooling

Masked mean pooling excludes padding tokens before the linear classification head.

07

Training and checkpoints

AdamW, cross-entropy, gradient clipping, a fixed seed and best-validation-accuracy checkpoint selection.

08

Evaluation and visualization

Held-out test evaluation after checkpoint reload; optional model-diagram export using torchview and Graphviz.

What “from scratch” means here: The encoder blocks and classification head are custom-trained. For the real Yelp experiments, the tokenizer and 384-dimensional frozen input embeddings are obtained from all-MiniLM-L6-v2. This is a bidirectional sentiment classifier, not a GPT-style generative LLM.

Why each stage matters

The encoder forms contextual token representations while ignoring padded positions in attention and pooling.

  • ✓Attention: learns token-to-token relevance through projected queries, keys and values.
  • ✓Residual paths: retain prior representations while adding information from attention and feed-forward layers.
  • ✓Pooling: aggregates non-padding token states into one review vector.
  • ✓Classification: maps the vector to negative and positive logits.

THREE EXECUTION MODES

Start small. Scale the experiment.

All modes share the same custom encoder; dataset loading and training configurations differ. The real-data modes download Yelp Polarity data and MiniLM resources unless already cached.

MODE 01OFFLINE / CPU

Smoke test

Synthetic Yelp-style review samples, a tiny tokenizer and random frozen embeddings. Exercises the complete training, checkpoint reload and evaluation path without a model download.

Yelp small run

Uses the Yelp Polarity dataset, a pretrained MiniLM tokenizer and frozen input embeddings. Enables the attention implementation and training configuration to be studied on real reviews.

MODE 03YELP / LARGER

Extended Yelp run

A larger requested dataset and longer training preset. GPU acceleration is optional when PyTorch detects CUDA; memory and runtime depend on hardware and review filtering.

Requested train50,000
Validation5,000
Test10,000

Real-data sample counts are requested values: length filtering can reduce the number of eligible examples. The smoke test is a correctness exercise, not a benchmark for Yelp accuracy.

RUN IT LOCALLY

Clone, install, train.

Use the commands below from Windows PowerShell. The script also runs in compatible Linux and macOS environments. For a first test, choose the offline smoke mode.

TERMINAL / Install dependenciesPython 3.12 · Windows PowerShell
git clone https://github.com/su394611-del/LLM-from-scratch.git
cd LLM-from-scratch
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m pip check
TERMINAL / Offline smoke testNo Hugging Face download
python transformer_from_scratch.py --smoke-test
TERMINAL / Train on Yelp subsetUses pre-trained tokenizer and embeddings
python transformer_from_scratch.py --train --sdpa
TERMINAL / Extended Yelp experimentResource-intensive preset
python transformer_from_scratch.py --full --sdpa
TERMINAL / Custom training optionsPowerShell backtick line continuation
python transformer_from_scratch.py --train --sdpa `
  --train-size 2000 --val-size 300 --test-size 300 `
  --batch-size 4 --max-len 128 --epochs 3 `
  --n-layers 3 --n-heads 6 --lr 0.0002
TERMINAL / Optional architecture exportRequires Graphviz executable to render
python -m pip install torchview graphviz
python transformer_from_scratch.py --smoke-test --visualize

EVALUATION & REPRODUCIBILITY

Measure more than training loss.

The implementation separates training, validation and test data. It selects the best checkpoint by validation accuracy, reloads that checkpoint and reports held-out test accuracy.

Training mechanics

Cross-entropy classification loss is optimized with AdamW. Gradient norms are clipped and a seed is set for repeatability. Training and validation losses and accuracies are printed after each epoch.

  • OptimizerAdamW
  • LossCross-entropy
  • Gradient clippingMax norm 1.0
  • Best checkpoint criterionValidation accuracy
  • Test evaluationAfter checkpoint reload

Validation status & scope

The project README reports a completed offline smoke test and saved checkpoint. It does not provide a standardized external benchmark or independently reproducible performance record in this website.

  • Offline synthetic exerciseDocumented as completed
  • Yelp benchmark scoreNot asserted
  • GPU throughput / VRAMHardware-dependent
  • Production deploymentNot claimed
  • Model outputBinary sentiment logits
Reproducibility note: The checkpoint saves the trained model state and configuration metadata, not the full frozen MiniLM embedding matrix. To reproduce real-data inference, load the matching tokenizer and embedding weights identified in the metadata.
